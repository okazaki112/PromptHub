## Summary

`fork-v0.6.5` 覆盖自 `fork-v0.6.4` 以来的 23 个提交，主题是备份恢复可靠性、关系图谱可用性与热度可视化。

- 关系图谱三档增强：文件夹底色、使用热度尺寸、关系分色与方向、选中才亮起的候选关联边一键落库、邻域聚焦与标签/根文件夹筛选。
- 使用热度热力图视图：按本机日期统计新建与版本修订，多选日期联动列表、年份导航。
- 备份恢复改为单事务批量写入，同规模数据由清空阶段约 9.5 秒降到端到端约 0.25 秒，且中途失败整轮回滚。
- 背景图本体进备份包并可恢复；媒体写入失败与文件缺失不再静默；>3.5MB 媒体的 base64 校验栈溢出修复；Prompt 按父先子后入库消除「引用关系不完整」误报。
- 选择性导出默认含版本历史，背景图与媒体开关分离。
- 图谱稳定性与列表滚动修复：hover 不再重热模拟、文件夹加载期不再全灰、点击 Prompt 不再跳回顶部。
- Windows 打包 winCodeSign 缓存自愈，安装包图标与版本信息不再被静默跳过。
