# Spec: 搜索结果选中项与移动目标

## Added Requirements

### FR-S1 查询未变时保持搜索结果选中项

当顶栏搜索词保持不变、后台刷新 Prompt/Folder 数据时，系统不得改变当前选中的搜索结果，也不得把结果游标重置到第一条。

**Scenario: 窗口重新聚焦**
- Given 用户已输入搜索词并切换到第 N 条结果（N > 1）
- When 应用窗口失焦后重新获得焦点，触发本地数据刷新
- Then 选中项保持第 N 条结果
- And 不重新选中第一条结果

**Scenario: 用户修改搜索词**
- Given 用户已输入搜索词
- When 搜索词文本发生变化
- Then 结果游标重置为 0
- And 若存在结果，选中第一条

### FR-S2 移动候选不受搜索/筛选裁剪

当搜索词或标签/类型筛选让列表只显示部分 Prompt 时，「移动到节点」候选仍保持当前文件夹/收藏范围下的完整 Prompt 集合（忽略搜索、标签、类型筛选），并继续排除锁定私密文件夹、自身与自身后代。

**Scenario: 搜索后移动**
- Given 搜索词只命中源 Prompt，目标 Prompt 不命中
- When 用户打开源 Prompt 的右键「移动到节点」
- Then 目标 Prompt 出现在候选中
- And 点击后调用移动并使用目标节点

## Invariants

- 搜索排序、过滤、Tab/Enter 导航语义不变。
- 移动候选仍禁止选择自身及后代。
- 无新增用户设置项。
